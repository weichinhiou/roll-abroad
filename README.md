# 大赴翁 Roll Abroad

> 醫院同仁的國際學術旅程：擲一顆骰子，走一趟出國赴會。
> 無界任意門・任務實驗室的第四款嚴肅遊戲。

**狀態**：規劃完成，尚未開始寫程式（2026-10-29）。目標是在 **2026-11-09 黑客松**前完成可以展示的版本。

## 是什麼

這是一款單人、短局的擲骰走格遊戲（roll-and-move），玩家從「投稿」一路走到「出國準備」「國際會議」「返國結案」。每格會觸發機會卡、命運卡或關卡，玩家的每個選擇會影響四種資源（時間、經費、精力、學術收穫），也會影響之後遇到的事件與最後的結局。

- 不買地、不收租，不是比誰先到終點，而是比誰在有限的資源下完成最有價值的旅程。
- 有兩條發表路線可以選：壁報、口頭報告。
- 遊戲裡的行政規則只寫重點概念；精確的金額與期限請到無界任意門查詢（需要登入）。

## 怎麼玩（本機）

- **雙擊 `start-game.cmd`**：會啟動本機伺服器，並打開 http://localhost:4191 。需要先安裝 Node.js。
- 或者在資料夾裡執行 `npm start`，再打開 http://localhost:4191 。
- **不要直接雙擊 `index.html`**：用 `file://` 開檔時，瀏覽器會擋掉 ES module 和資料讀取，畫面只剩空殼，畫面上會顯示提示。
- 上線到 GitHub Pages 之後，直接開網址就可以玩，不需要這些步驟。
