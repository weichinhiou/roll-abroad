# 出國會議心得素材盤點（2026-11-04）

對 2018–2025 全院出國開會類報告彙編（6 冊 PDF，228 篇，約 216 萬字）做挖礦，
目的是找「值得做成遊戲關卡／事件卡」的真實情節，供縮短一輪遊戲時間的問題解方。

## 一、素材庫概況

| 項目 | 數值 |
| :--- | :--- |
| 報告篇數 | 228（去重 2018 年兩冊內容相同） |
| 年度涵蓋 | 2018 / 2019 / 2020–2022 / 2023 / 2024 / 2025 |
| 抽到時間資料的篇數 | 202 篇 |
| 行程天數中位數 | 6 天（P25 4 天、P75 8 天、最長 11 天） |
| 回國→交報告天數中位 | 17 天（P75 28 天、最長 80 天） |

時間資料對遊戲節奏有意義：真人一趟是 4–8 天的行程、回國後再隔半個月才寫得出報告。
現在遊戲一輪只有 24 格（4 章各 6 格），可以對應「出發→會場→返程」但砍掉「回國後」那
段真實存在的沉澱期——這是縮短一輪時間的具體解法之一，見第四節。

## 三、素材定位（使用原則）

- 下面每筆素材只寫「情境改寫＋彙編年份與頁碼」，**不貼心得原文、不寫姓名／科別／職稱**，
  符合 plan 內容邊界（會計金額、處罰細節、原文皆不進 repo）。
- 報告本身就是歸國後的工作產物（`出國報告`體例：摘要／目的／過程／心得及建議／附錄），
  所以「寫報告」不該只是結算畫面——它就是第四章的主軸，詳見第五節。
- 2020–2022 是疫情年（81 頁只有 8 篇），內容以線上會議、檢疫規則變動為主，可用來做
  特殊路線或彩蛋卡，不建議當主線素材。

## 五、一輪遊戲時間為什麼短、素材怎麼解

真人心得的時間軸其實很長：出發前至少幾個月在準備摘要與申請、旅程 4–11 天（中位 6 天）、
回國後 17 天才交出報告（P75 28 天、最長 80 天）。遊戲現在 24 格、4 章各 6 格，把這種
多個月的節奏壓進幾分鐘，問題不在「事件不夠」，而在「回院後」這一章只有 5 格，而素材顯示
那一段有獨立張力（繳回補助、論文發表期限、教學傳承、對臨床的落地）。

對症的做法，按建議順序：

1. **擴張第四章**（24 → 32 格，多加 8 格都在「回院後」）：素材密度夠，D、加「一年內有無
   發表論文」的懸念、教學傳承（228 篇裡 93 篇提及）都可用。重點是新增格子都帶
   `milestone: final` 的延伸，結算時多了「你兌現了哪一條承諾」的選項。
2. **加 8 張新卡**（上面 A–H）：不動格子、不動引擎，只加卡池的厚度，落地成本最低。
3. **連鎖事件**：現在 `requires` 只用在口報 Q&A，可以更廣泛用，像是「有在會場跟人交換
   聯絡」→ 回國後可以啟動「會後 Email 的延伸」，把單張卡擴成兩段式。
4. **不要做的**：拿「疫情線上参会」當主線路線（只有 52 篇且集中在一年），會偏離 228 篇
   的主體經驗；也不要再加簽證／行李卡（素材撐不起兩張不會重複的卡）。

## 六、新卡草稿（A–H，依 `data/events.json` 格式，尚未寫入檔案）

```
A 「上台前，資料換了一版」      deck: chance  route: oral  tone: real
   大會工作人員在你上場前十分鐘遞來一張補充資料，說是共同作者剛傳來的。
   選項一：臨時說進去、放在結論前 → 時間 −1、知識 +1（聽眾有聽到最新版本）
   選項二：照原稿講完、會後再補說明 → 知識 +1（節奏穩，最新結果沒被提到）

B 「拜會的長官臨時不能來」      deck: fate    route: both  tone: real

   選項一：改聽隔壁場次的演講 → 知識 +2、精力 −1
   選項二：在會場把白天的筆記整理掉 → 精力 +1、知識 +1

C 「海報作者必須在場」          deck: chance  route: poster tone: real
   委員說明：作者要在自己的海報前站滿時段，隨時接受詢問。
   選項一：全程站在海報前解說 → 知識 +2、精力 −2
   選項二：跟同區作者輪流看板，互相代班 → 知識 +1、社交 true

D 「補助附了一條條件」          deck: fate    route: both  tone: real
   補助公文的備註寫著：一年內要把成果發表在國外期刊，否則要繳回。
   選項一：回去就先排投稿計畫 → 時間 −1、知識 +1
   選項二：等到回國後再說 → 無效果、flag 提醒追蹤

E 「有沒有人告訴你」            deck: chance  route: both  tone: real
   你才輾轉聽說，其實還有一筆結餘款可申請——沒有公告，要自己問。
   選項一：承辦窗口問清楚 → 時間 −1、金錢 +1
   選項二：算了，公費照原計畫 → 時間 +1

F 「走錯出口，33 度走 15 分鐘」  deck: fate    route: both  tone: funny
   下車後方向錯了，烈陽下拖著行李走到報到會場，T 恤濕了一半。
   選項一：堅持走到、查地圖 → 精力 −2、時間 −1
   選項二：先找地方休息再搭一站 → 金錢 −1、時間 −2

G 「工作坊跟你的場次撞期」       deck: chance  route: both  tone: real
   會場角落有場低價的工作坊，主題正是你一直想學的；但撞上你排定的發表場次。
   選項一：照原排程聽完你的場次 → 知識 +1
   選項二：去工作坊 → 知識 +2、時間 −1（錯過原排定的場次）

H 「預算下來了，海報還沒寫」     deck: fate    route: both  tone: real
   補助核准了，但距離截稿不到一週；本來沒打算再多寫一份海報。
   選項一：把原本的資料彙整成海報 → 精力 −2、知識 +2
   選項二：維持原計畫，錢用在交通與住宿 → 金錢 +1
```

  樣本數分別為 202 與 200 篇。

未驗證（請留意）：
