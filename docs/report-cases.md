## 怎麼用

1. **已經放進遊戲的（2026-10-29）**：A1 → `T01`（壁報線）、B2 → `T02`（口報線）、A4 → `T03`、C1 → `T04`；B1 則是把原本的 `F-usb`「檔案打不開」改寫成「隨身碟讀不出來」。卡片總數補到 24 張。D5 還沒放進去，可以之後當作 S02 合作種子的起點。
2. **真實改編的標記**（Jean 2026-10-29 要求：「讓大家覺得有趣，這麼戲劇竟然是真的，也不會和遊戲劇本弄混」）：在卡片資料加上 `"trueStory": "院內同仁真的遇過：……"`。畫面上，卡片內文下方會出現紅色框「📌 真實改編」，玩家做完選擇後，行程紀錄也會再記一行。沒有 `trueStory` 的卡就是遊戲劇本；`tone: "real"` 只表示「寫實」，**不代表真的發生過**。`trueStory` 只寫情境，不寫任何可識別的細節。
3. 涉及行政的 C 類卡，只寫「要追蹤簽核」「先問承辦」這類概念，精確規定用「任意門」道具導向任意門。
4. 數值先照上表的構想填，再用 1,000 局模擬調整。

## 第一批盤點時的限制

- 只用關鍵字撈，沒有逐篇細讀 234 篇，一定還有沒撈到的好故事（例如「迷路」「遺失」「簽證」在全文中都是 0 筆，不代表沒發生過，可能只是寫法不同）。
- 改寫後有沒有可能被當事人認出來：已經拿掉姓名、年份、科別、會議名稱，但像「颱風關閉機場」這類事件，同科同事仍可能認得。由於心得報告本來就公開在醫院官網，風險低，但沒有問過當事人。
- 疫情時期的隔離規定（例如「0＋7 自主健康管理」）已經過時，所以不採用。
